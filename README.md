# 长春市六年级体能测试评分系统

基于国家学生体质健康标准，针对长春市六年级学生体测项目的自动评分工具。

## 功能特性

- **性别选择**：支持男生/女生两套评分标准
- **BMI 双模式**：身高体重自动计算 / 直接输入 BMI 值
- **7 项指标**：BMI、肺活量、50米跑、坐位体前屈、跳绳、仰卧起坐、50×8往返跑
- **线性插值**：两档之间自动插值计算精确得分
- **跳绳加分**：超满分后每多 2 个加 1 分（原始分），满分 100 + 加分上限 20 = 最多 120 分，加权后最多 12 分
- **部分得分**：缺少项目时按已输入项目权重比例计算
- **低分预警**：单项得分低于 80 分整行标红提醒
- **50×8 双输入**：支持分+秒方式输入成绩

## 使用方式

### 方式一：推荐（方便修改规则）

用 HTTP 方式打开（如 VS Code 安装 Live Server 插件后右键 → Open with Live Server），或启动本地服务：

```bash
npx http-server -p 8080
```

然后访问 `http://localhost:8080/体测评分.html`。

### 方式二：直接双击

双击 `体测评分.html` 在浏览器中打开，无需安装任何软件。

## 规则配置

> **重要：两种打开方式对应的修改方法不同。**

### 如果用 HTTP 方式打开（推荐）

修改 `config.json`，刷新页面即可生效，无需改代码。

### 如果直接双击 HTML 打开

由于浏览器安全策略限制，直接双击无法加载外部 `config.json`。修改规则需要编辑 `体测评分.html`，搜索 `EMBEDDED_CONFIG`，修改对应的 JSON 数据。

| 配置项 | 说明 |
|--------|------|
| `weights` | 各项目权重（满分100%） |
| `genders.male/female` | 男女生评分标准 |
| `genders.*.bmi.ranges` | BMI 分档规则 |
| `genders.*.items` | 各项目分数-成绩映射表 |
| `bonus.ropeSkip` | 跳绳加分规则 |

## 评分标准

| 单项指标 | 权重 |
|---------|------|
| 体重指数（BMI） | 15% |
| 肺活量 | 15% |
| 50米跑 | 20% |
| 坐位体前屈 | 10% |
| 1分钟跳绳 | 10% |
| 1分钟仰卧起坐 | 20% |
| 50米×8往返跑 | 10% |

## 数据来源

原始数据文件：

- `体育考试PPT(8)(1).pptx` — 体测评分说明PPT
